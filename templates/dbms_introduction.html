🗄️ Introduction to DBMS

DBMS stands for Database Management System. It is software that helps users create, store, retrieve, update and manage data efficiently.

Features of DBMS

  • Easy Data Storage
  • Data Security
  • Data Backup & Recovery
  • Data Sharing
  • Reduced Data Redundancy
  • Data Integrity

Advantages of DBMS

  • Fast Data Access
  • Better Security
  • Easy Data Management
  • Multi-user Support
  • Less Data Duplication

Example

Student Database

ID   Name      Course
--------------------------
1    Shalini   BCA
2    Divya     BCA
3    Nidhi     MCA

Explanation

In this example, all student records are stored in a database. A DBMS allows users to insert, update, delete and search these records easily.
