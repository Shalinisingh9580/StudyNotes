🔑 DBMS Keys

Keys are used to identify records uniquely.

Types of Keys

  • Primary Key
  • Foreign Key
  • Candidate Key
  • Alternate Key
  • Composite Key
  • Super Key

Example

Student

Roll No   Name

101       Shalini

102       Rahul

Roll Number is the Primary Key because every student has a unique roll number.
