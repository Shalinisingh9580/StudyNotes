📦 Variables in Python

Variables are used to store data in Python. A variable is created when you assign a value using the = operator.

Example

name = "Shalini"
age = 22

print(name)
print(age)

Rules for Variable Names

  • Must start with a letter or underscore (_).
  • Cannot start with a number.
  • Cannot contain spaces.
  • Variable names are case-sensitive.
