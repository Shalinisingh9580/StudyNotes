🔢 Data Types in Python

Data Types define the type of data that a variable can store.

Common Data Types

  • int → Integer Numbers
  • float → Decimal Numbers
  • str → Text or String
  • bool → True or False
  • list → Collection of Items
  • tuple → Ordered Collection
  • dict → Key-Value Pairs
  • set → Unique Values

Example

age = 22
price = 199.99
name = "Shalini"
isStudent = True

print(type(age))
print(type(price))
print(type(name))
print(type(isStudent))

Output

<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
