➕ JavaScript Operators

Operators perform operations on values and variables.

Types

  • Arithmetic Operators
  • Assignment Operators
  • Comparison Operators
  • Logical Operators

Example

let a = 10;
let b = 5;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);

Output

15
5
50
2
