🔢 Java Data Types

Data types specify the type of value that a variable can store.

Primitive Data Types

  • int
  • double
  • float
  • char
  • boolean
  • byte
  • short
  • long

Example

int age = 22;
double marks = 95.5;
char grade = 'A';
boolean pass = true;

System.out.println(age);
System.out.println(marks);
System.out.println(grade);
System.out.println(pass);

Output

22
95.5
A
true
