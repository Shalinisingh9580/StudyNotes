📦 Java Variables

Variables are used to store data values in Java. Every variable must have a data type.

Syntax

dataType variableName = value;

Example

public class Main {

    public static void main(String[] args) {

        String name = "Shalini";
        int age = 22;

        System.out.println(name);
        System.out.println(age);

    }

}

Output

Shalini
22

Common Data Types

  • int → Integer Numbers
  • double → Decimal Numbers
  • char → Single Character
  • boolean → true / false
  • String → Text
