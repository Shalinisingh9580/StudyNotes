🏗️ DBMS Architecture

DBMS Architecture defines how users interact with the database system.

Types of Architecture

  • 1-Tier Architecture
  • 2-Tier Architecture
  • 3-Tier Architecture

Explanation

1-Tier: User directly accesses the database.

2-Tier: Client communicates directly with the database server.

3-Tier: Client → Application Server → Database Server.
