➕ Java Operators

Operators perform operations on variables and values.

Types

  • Arithmetic
  • Comparison
  • Logical
  • Assignment
  • Unary

Example

int a = 10;
int b = 5;

System.out.println(a+b);
System.out.println(a-b);
System.out.println(a*b);
System.out.println(a/b);

Output

15
5
50
2
