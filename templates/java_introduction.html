☕ Introduction to Java

Java is a high-level, object-oriented programming language developed by Sun Microsystems (now owned by Oracle). It was created by James Gosling in 1995. Java is widely used for developing desktop, web and Android applications.

Features of Java

  • Simple and Easy to Learn
  • Object-Oriented
  • Platform Independent
  • Secure
  • Robust
  • Multithreaded
  • High Performance

Applications of Java

  • Desktop Applications
  • Web Applications
  • Android App Development
  • Banking Software
  • Enterprise Applications
  • Game Development

First Java Program

public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}

Hello, Java!
